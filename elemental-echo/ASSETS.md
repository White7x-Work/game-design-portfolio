# 《元素回响》美术与音频素材需求清单

> 当前 v1 状态：**零外部素材**。卡面图案用字符符号（`✦ ❋ ⚡ ◍ ▩` 等）、元素用 emoji、粒子用 Canvas、音效用 Web Audio 实时合成。
> 本文档列出「要换成正式美术时需要哪些素材」，供你判断成本或外包。
>
> **P0 素材的可直接复制生图提示词**见 [ART_PROMPTS.md](ART_PROMPTS.md)。

## 0. 优先级总览

| 级别 | 含义 | 项数 |
|---|---|---|
| **P0** | 没有它无法上架 / 观感无法接受 | 18 |
| **P1** | 明显提升品质，建议首版就有 | 62 |
| **P2** | 锦上添花，可后续迭代 | 45 |

## 4. 场景背景（P1，4 张）

| 素材 | 规格 | 数量 |
|---|---|---|
| 标题主视觉 | 750×1334 竖屏（或 1125×2001 @1.5x） | 1 |
| Act I 元素林地 | 750×1334 | 1 |
| Act II 熔脉深渊 | 750×1334 | 1 |
| Act III 雷暴之巅 | 750×1334 | 1 |

**重要限制**：背景必须是**低对比度、暗色、中间留空**，因为战斗区在上方、手牌在下方，背景太花会干扰卡牌识别。建议整体压暗到 30% 不透明度使用。

**可选加分**：每张背景拆 2 层做视差（远景 + 中景），实现成本低、效果明显。

## 6. 特效素材（P2，可用现有粒子系统替代）

当前 10 组反应 + 5 种元素爆发的特效**已用 Canvas 粒子实现**，能用但偏"程序感"。若要升级：

| 素材 | 规格 | 数量 | 说明 |
|---|---|---|---|
| 反应特效序列帧 | 256×256，6~8 帧横向排布 | 10 组 | 焚风/熔岩/蒸汽/过载/霜寒/泥沼/感电/沙暴/暴风/磁暴 |
| 元素爆发光爆 | 512×512，8 帧 | 5 | 每元素一种 |
| 冲击波 / 命中闪光 | 128×128，4 帧 | 3 | 通用复用 |
| 卡牌打出拖尾 | 已用 CSS 实现 | — | 可不做 |

**我的建议**：优先做「爆发」和「过载」两个最常用、最需要冲击力的，其余保留粒子。

## 9. 替换方式（技术对接说明）

所有占位都已留好替换点，替换时**不需要改游戏逻辑**：

| 占位 | 位置 | 替换方式 |
|---|---|---|
| 卡面图案 | `code/js/data.js` → `CARD_GLYPHS` | 把 `'✦'` 换成 `assets/cards/spark.png`，并把 `codexCardHTML` / `cardFace` 里的 `<div class="cx-glyph">` 改为 `<img>` |
| 元素图标 | `data.js` → `ELEMENT_GLYPH` | 同上 |
| 敌人立绘 | `ui.js` → `screenBattle` 的 `.enemy` 区块 | 加一个 `<img class="enemy-art">` |
| 背景 | `code/css/style.css` → `.screen` | 给 `.battle-screen` / `.map-screen` 加 `background-image` |
| 按钮与面板 | `code/css/style.css` | 把 `border-radius` + `background` 换成 `border-image` |
| 音效 | `code/js/fx.js` → `SFX` 对象 | 保留函数名，内部改为播放音频文件（需首次交互解锁，已有解锁逻辑） |

素材统一放在 `elemental-echo/code/assets/` 下按 `cards/ elements/ enemies/ ui/ bgm/ sfx/` 分类。

## 10. 建议交付顺序

如果分阶段采购，我建议这个顺序（每步都能立刻看到效果）：

1. **P0 上架素材**：图标 512、横幅 1920×1080（否则无法发布）
2. **3 个 Boss 立绘** + 标题主视觉 —— 玩家第一印象与记忆点
3. **5 个元素图标** + 卡牌框 —— 提升最大，影响每一帧
4. **6 张代表性卡面** —— 覆盖主要卡牌
5. **BGM 3 首 + 12 个核心音效** —— 体验质变
6. 其余普通敌人、事件立绘、剩余卡面、特效序列帧

## 11. 需要你确认的三件事

1. **是否外包**？如果外包，我可以把这份清单整理成可直接报价的工序表（含每项工时量级）。
2. **风格方向**：我建议「暗色 + 高饱和元素辉光 + 玻璃质感卡牌」，与你当前的 UI 一致。要不要先出 2~3 张风格示意图再定？
3. **包体预算**：如果对首包体积敏感（小游戏建议 <20MB），P2 的特效序列帧和 6 首 BGM 是最大占用，可以砍。
